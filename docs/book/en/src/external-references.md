# External References

- [Rust API documentation (docs.rs)](https://docs.rs/ocas) — auto-generated
  reference for the public Rust API, built from the published crate with
  **portable features only** (backend features such as `gmp`/`mpfr`/`flint`
  that require system C libraries are excluded). For the full backend API
  docs, build locally with `cargo doc -p ocas --features gmp,mpfr,flint
  --no-deps`.
- [crates.io registry page](https://crates.io/crates/ocas) — published
  releases, feature flags, and dependency graph.
- [GitHub repository](https://github.com/charleshzh/ocas) — source code,
  issue tracker, and contribution guide.
- [Documentation site](https://charleshzh.github.io/ocas/latest/) — this
  book, served from GitHub Pages. Versioned snapshots live under
  `/ocas/v<version>/` for each release tag.
