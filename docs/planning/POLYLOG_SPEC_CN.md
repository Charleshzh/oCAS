## 1. 目标与范围

**目标**：让需要二重对数（dilogarithm）的原函数第一次可表达、可数值核验、可自证。
0.30.0 终态的 1892 题库中，122 例参考答案含 `polylog`（占未解 8.0%），
归因自 2026-09-12 后未再审计——本规格要求把「头」与「归约」分开验收，
不承诺这 122 例的可及子集一次全解。

**范围内（0.31a）**：

1. `polylog(2, z)` / `Li₂(z)` 的**函数头**：解析、显示、求导、f64 求值（实值域）。
2. **数值 oracle**：新增头进入 `integral_eval` 的 f64 求值分派，
   使含 Li₂ 的候选答案可被独立数值核验。
3. **Li₂ 归约骨架**：只覆盖「对数-有理积分」里能自证的一小块，
   至少打通一条 `∫ log(1−x)/x dx = −Li₂(x)` 级别的完整闭环。
4. **两类语料的区分处理**（验收口径见 §6）：
   - A 类「被积式含 `polylog`」：`∫ R(x)·polylog(2, a+bx) dx` 型，
     靠导数表 + 分部 + 有理化处理；
   - B 类「被积式为初等、原函数需 Li₂」：如 `∫ log(1−x)/x dx`，
     靠归约骨架识别对数-有理积分。

**范围外（明确后移，见 ROADMAP 0.31b）**：

- `polylog(s, z)` 的 `s ≥ 3`、任意符号阶、复数参数与复数返回值（0.31a 只做 `s = 2`；
  `s = 1` 应化简为 `−log(1−z)`，属于头的化简规则而非归约）；
- Meijer G / Slater 展开、`Outcome::ProvedNonElementary` 的产出方；
- 更一般的对数积分（`Li₃`、多重对数、`Ti₂` 等，`inverse_trig.rs` §2.5 已作为
  「polylog territory」诚实拒绝的那些形状）。

**非目标声明**：本文**不写实现代码**。§4 的公式只列路线与「待核对项」，
具体推导在实现 PR 中逐行核对来源并记录于 §7。

## 2. `polylog`/Li₂ 函数头定义与导数

- 头名 `polylog`，两参数 `polylog(s, z)`；0.31a 接受 `s = 2`，其余阶诚实拒绝。
  显示可保留 `polylog(2, z)`（与语料记法一致），不强制引入 `Li₂` 别名。
- 定义（解析延拓的实值域形式）：`Li₂(z) = Σ_{k≥1} z^k / k²`，`|z| ≤ 1`；
  `z = 1` 时 `Li₂(1) = π²/6`，`Li₂(0) = 0`，`Li₂(−1) = −π²/12`。
- 导数表（写入 `derivative.rs` 的头规则）：
  - `d/dz Li₂(z) = −log(1 − z) / z`；
  - 链式：`d/dx Li₂(u(x)) = −log(1 − u)·u'(x)/u`，`u'` 走既有导数表。
  - 因此 `∫ log(1−x)/x dx = −Li₂(x)` 是**同一恒等式的反向使用**，不是新恒等式；
    归约骨架必须与导数表共用同一份定义，避免「导数一套、归约另一套」。
- 化简规则（最小集，避免过度展开）：
  - `polylog(1, z) → −log(1−z)`；
  - `polylog(2, 0) → 0`、`polylog(2, 1) → π²/6`（数值化只在常量折叠开启的路径上）；
  - `z` 含 `exp`/`log` 塔元素时不做改写（塔层归 0.31b）。
- **实值语义**：Li₂ 在 `z ∈ (−∞, 1]` 取实值，`z > 1` 起有虚部。
  0.31a 的 oracle 只在 `(−∞, 1)` 采样；候选答案若只能形式正确而实值域不覆盖样本点，
  oracle 判 `Indeterminate`（报告，不算成功也不算错案）。
- 不允许把 `Li₂` 当作不透明符号静默参与算术：证书门与语料 harness 的
  `Integral` 残留判定都要求「头被识别、答案被核验」，见 §5、§6。

## 3. 数值 oracle 核验方案

沿用 0.27.3 对 `Ei`/`Si`/`Ci`/`Shi`/`Chi`/Fresnel 的落地模式：**先核验头，再补归约**。

1. **f64 头求值**（`ocas-tests/src/integral_eval.rs` 的 `eval_f64` 分派）：
   - `|z| ≤ 0.5`：直接级数 `Σ z^k/k²`，项数上限见 §5，误差目标 `≤ 1e-12`；
   - `0.5 < z < 1`：反射公式加速（`Li₂(z) = π²/6 − log z·log(1−z) − Li₂(1−z)`，
     `1−z < 0.5` 后走级数）；公式在实现前逐行核对，并记录到 §7；
   - `−1 < z < 0`：级数直接收敛，无分支问题；
   - `z ≤ −1`：用反演公式（`Li₂(z) = −π²/6 − ½·log²(−z) − Li₂(1/z)`，
     结果仍为实值；公式实现前逐行核对并记录到 §7）；
   - `z = 1`：常量 `π²/6`；`z > 1`：返回 `Unsupported`（实值域外）。
2. **导数自检**：`(Li₂(z+h) − Li₂(z−h))/2h` 与 `−log(1−z)/z` 在网格上比对，
   相对误差 `≤ 1e-9`（步长在实现时按数值条件选定并记录）。
3. **原函数数值门**：`verify_antiderivative` 已有的「候选答案求导 vs 被积式
   多点采样」机制直接复用；新增头进入 `eval_f64` 后，含 Li₂ 的候选即可被核验。
   采样点须避开 `z = 1` 的奇点与对数分支割线，避开策略必须在实现中显式记录。
4. **独立参考值**：网格点（如 `−0.9, −0.5, −0.1, 0.1, 0.3, 0.5, 0.7, 0.9`）
   的参考值由 mpmath/SymPy 40 位生成，作为测试数据入库；不得用 oCAS 自己的
   级数结果当参考（自证必须另立一路）。

## 4. Li₂ 归约路线（对数-有理积分）

**目标片段**：被积式可化为 `p(x)/q(x)` 与 `log(1 − u(x))` 的代数组合，
且 `u` 为仿射（`u = a + b·x`）或可由已知塔元素线性表示——此时归约归结为
「对数-有理积分」的经典形式 `∫ R(x)·log(1−u) dx`，其中 `R` 有理。

**路线（按依赖顺序）**：

1. **部分分式先行**：`R` 拆成部分分式，把 `∫ log(1−u)/(c + d·x) dx` 化为
   `∫ log(1−u)/u` 与 `∫ log(1−u)/(u − α)` 两类（`α` 为极点）。
   - `∫ log(1−u)/u du = −Li₂(u)`（§2 恒等式的反向）；
   - 极点项由 `Li₂(1 − (u−α)/...)` 的平移/缩放恒等式处理——
     **具体恒等式清单（Landen、反射、反演）实现前逐行核对 Lewin/Raab，
     不得凭记忆写公式**；核对结果记录到 §7。
2. **u 的仿射性检查**：只收 `u = a + b·x`（`a, b` 为常量或已成塔元素）。
   参数非线性、或 `u` 含未处理塔元素 → 拒绝（§5）。
3. **A 类：被积式含 `polylog`**：`∫ R(x)·polylog(2, u) dx` 用导数表 + 分部。
   分部后落到「`∫ log(1−u)` 的多项式/有理权」型，回到步骤 1。
   只处理有限的、可核对的形状（多项式权为低次、`R` 部分分式后极点个数 ≤ 预算）。
4. **证书闭环**：发射前必须用**数值 oracle 自证**（§3 第 3 条），
   并保留「形式自证」的检查点：导数回代后与被积式逐项比较（与 0.30.0
   `logpart.rs` 的 `Πv == d` 自证同构，形状更弱但方向一致）。
5. **未达片段的处理**：落到 `polylog` 但恒等式清单未覆盖 → 诚实拒绝，
   返回 `Integral(...)` / 其它既有兜底；**禁止**发射未自证闭式（错案门优先）。

**实现先后顺序（0.31a 内部）**：头 + 导数表 + oracle（可独立验收）→
`∫ log(1−x)/x` 一课闭环 → 部分分式接骨架 → A 类基本形 →
最后才开 `u` 的仿射参数化。任何一步触墙钟/超时门即停，不进入下一步。

## 5. 拒绝面与预算

**拒绝面（必须诚实拒绝，不得返回错误闭式）**：

| 情形 | 判定 | 去向 |
|---|---|---|
| `polylog(s, z)`，`s ∉ {1, 2}` | 头层拒绝 | 0.31b |
| 被积式含 `polylog`，但权重非有理 / 参数非仿射 | 归约层拒绝 | 0.31b |
| 初等被积式、归约落入恒等式清单外 | 归约层拒绝 | 0.31b |
| `u` 的实值域越出 `(−∞, 1)`（如 `u > 1`） | oracle 判 `Indeterminate`，形式结果可留但**不计 solved** | 记录 |
| 嵌套 Li₂ / 多重对数 / 复数参数 | 拒绝 | 0.31b |
| 符号常量塔上的 `polylog` | 拒绝 | 0.31b（与 0.29.0 符号指数族同源） |

**确定性预算（算法预算，不用墙钟换解）**：

- 归约步数 `MAX_POLYLOG_STEPS = 8`（与 `special.rs` 的 `MAX_SPECIAL_STEPS=16` 同量级，
  先取更保守值）；
- 归约项数 ≤ 256、表达式节点 ≤ 2000（证书层既有 `nodes ≤ 2000` 同额）；
- 头求值级数项 ≤ 4096（`|z| ≤ 0.5` 时误差远低于 `1e-12`）；
- Li₂ 嵌套深度 ≤ 2（0.31a 实际只允许 1）；
- **墙钟政策**：0.31a 不设逐题墙钟预算，也不允许用「加预算」换解——
  0.29.0 证书 `budget` 400→1200 与 0.30.0 W6a 的 +29 解/破三门都是先例；
  整库门 = 0.30.0 基线 489.5 s × 1.10 ≤ **538.5 s**（见 ROADMAP 0.31 节），
  且发布前记录两次同树复跑方差。
