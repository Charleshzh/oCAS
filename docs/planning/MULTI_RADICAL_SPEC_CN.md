## 1. 问题与片段边界

### 1.1 问题

被积函数含 **≥2 个不同根式基** `S₁^(p₁/q₁)、S₂^(p₂/q₂)、…`（`Sᵢ` 为互不相同的非常量
底）。现有引擎全部是**单基**假设：`sqrt_quadratic` 只认一个 `√q`；`binomial` 的
`x=t^L` 有理化只接受单个线性基的分数幂；`halfpower` 显式拒绝双基积（其模块文档
60–67 行）。99 例因此整体回退。

### 1.3 片段总原则（划界即设计）

1. **本波只做原子层归约**：把多根式基被积函数归约为**单根式基**或**有理** t-形，
   然后回交现有引擎（`sqrt_quadratic` / `binomial` / `rational` / `elliptic`）。
   **不改动 Risch 塔**（`tower/build.rs` 的非整数幂拒绝保持不变）；代数函数域的一般
   理论（Trager 积分基、代数 Hermite）是 0.30.0 另一条线，与本波正交。
2. **定理覆盖的参数化族**：每条归约必须是一个定理族（如「任意关于
   `x, √(a+bx), √(c+dx)` 的有理函数可被 `t²=(a+bx)/(c+dx)` 有理化」），
   不允许按题库逐题匹配形状。
3. **诚实拒绝**：归约前提不满足、合并后的单基引擎拒绝、t-形残留 `Integral`、
   数值门/证书不通过——任一发生即返回 `None`，链继续下行；绝不输出部分猜测。
4. **确定性预算**：新阶段自带预算常量（§3.2），单阶段总工作量有界。
5. **输出必须过符号证书**：`certify.rs` 根式层（0.30.0 已落地）天然支持多根式基
   ——每个不同基一个生成元 `rᵢ`、一个关系 `rᵢ^qᵢ = Sᵢ`，三角列约化判零；
   `MAX_CERT_RADICALS=8` 覆盖本片段全部子类。证书拒绝 ⇒ 答案不得发射。
6. **输出形状不得重新匹配 `rational`/`risch` 入口模式**（幂等不变式，同
   ALGEBRAIC_RT §5）；t-形一律为有理函数或单基根式形，回积分经 `integrate_raw`
   并以 `contains_integral` 检查拒绝残留（`sqrt_quadratic` S3 与 `binomial` 先例）。
7. **`chain::parts_active()` 作用域内不得把残项升级为完整超越答案**
   （`rubi-01646` 教训，ALGEBRAIC_RT 实现偏差记录第 1 条）：本阶段若产生残项，
   parts 作用域内只准保留诚实 `Integral` 残项形状，交由链外/顶层解析。
8. **实值分支语义单独文档化**（§4）：合并、代换、片层因子的成立区间全部显式记录。

## 2. 各子类归约算法

### 2.1 公共预处理（所有子类共享，按序执行）

```
P1 同基合并：同一底 S 的各分数幂合并为 S^(Σpᵢ/qᵢ)（复用 kernel_subst 的
   combine_like_powers，预算 MAX_POW_GROUPS=32/MAX_POW_EXP=64 不变）。
P2 同因子提取：基之间共享非常量多项式因子时先提取——
   (b·x+c·x²)^(p/2) = x^(p/2)·(b+c·x)^(p/2)·σ，其中 σ 为片层因子（§4.2）。
   例：rubi-00537 x^(3/2)/√(b·x+c·x²) → x/√(b+c·x)（单基，直接出局）。
P3 可分解基检查：二次基在 ℚ（系数符号允许）上分解为两仿射因子 → 降入 MR-L；
   完全平方三项式 → MR-P。分解只做完全平方与显式双仿射两种有界形状，
   不做一般因式分解调用（成本纪律）。
P4 基收集与预算：收集不同根式基 {Sᵢ, pᵢ/qᵢ}，个数 > MAX_MR_BASES(=4) 或
   任一 qᵢ > MAX_MR_Q(=4) 或节点数 > MAX_MR_NODES(=200) → 拒绝。
```

### 2.2 MR-L：纯仿射基半幂桶（27 例，W4 主力）

**定理（双仿射基 Möbius 有理化）**：设 `u = a+b·x`、`v = c+d·x`（`a,b,c,d` 关于 `x`
常量，`a·d−b·c ≢ 0`），`R` 为有理函数，则

```
∫ R(x, u^(p₁/2), v^(p₂/2)) dx,   t = √(u/v)  ⇒
x = (a − c·t²)/(d·t² − b),   u = (a·d − b·c)/(d·t² − b),   v = (a·d − b·c)/(d·(d·t²−b)/… )
```

全部根式化为 `t` 的幂，`dx` 为 `t` 的有理函数——**t-形是纯有理函数**
（SymPy 核验：§5 例 L3 的 t-形 `−2t²(2t²−1)²/(3t²−1)³`、例 R1 的
`t²(8t²−4)/(3t²−1)²` 均为有理式）。随后：

1. t-形经 `integrate_raw` 回积分（有理后端 + 0.30.0 RT 代数根；`√3` 等常量根式
   系数经证书根式层认证，ALGEBRAIC_RT §4 已就位）；
2. 回代 `t = √(u/v)`；
3. **拒绝条件**：`a·d−b·c ≡ 0`（基成比例——本就是单基）、t-形非有理（结构检查）、
   t-积分残留 `Integral`、节点/预算超支。

**同根合并子情形**（优先于 Möbius）：两基之积 `u·v` 为二次式时，
`√u·√v = √(u·v)`（成立条件与分支风险见 §4.1）把**积形**直接坍缩为单二次基，
交 `sqrt_quadratic`。判定规则：

- 被积函数关于两基**同号**（都是 `+1/2` 幂次奇偶性一致的积）且合并后的
  `√(u·v)` 落在 `sqrt_quadratic` 接受面（次数 ≤ 2）→ 合并；
- **商形不合并且走 Möbius**（`√u/√v = √(u/v)` 的分支风险更大，且 Möbius
  已覆盖，无须承担合并风险）；
- 同斜率对（01384：`√(2+bx)·√(6+bx)`，积为二次）与互为相反平移对
  （01373：`√(−1+dx)·√(1+dx) = √(d²x²−1)`）是合并的直接受益例。

**≥3 个仿射基**（如 00246 三基、00634/01704 四基）：两两配对逐轮归约——
先选使合并/代换后剩余基最少的一对执行，每轮后重新收集基；任一轮失败即整体
拒绝（不做指数级配对搜索：配对选择按「同斜率 > 同因子 > 节点增量最小」的
固定优先级确定化）。**4 基全异构的一般情形明确不保证**（见 §7）。

### 2.3 MR-Q：二次基对（25 例）

**关键事实（诚实记录，先写死）**：两个不同二次基 `√q₁·√q₂ = √(q₁q₂)` 的被开方是
**四次式**——一般情形是**椭圆积分**而非初等积分（SymPy 核验：§5 例 Q2 的 Möbius
t-形仍含 `√(3t²+1)·√(−1/(2t²−1))`，无法有理化）。这正是 0.27.3 仿射 `cos` 半幂簇
136 例的根因同族。因此 MR-Q 分三层：

1. **可坍缩层（W4 做）**：P2/P3 预处理后降为单基或 MR-L 的全部情形
   （可分解基、共享因子、完全平方），以及 `q₁·q₂` 恰为**完全平方或 ≤2 次**
   的退化积（判定了才合并，不猜）。代表：01373、00537、00469/00636/00677/01832
   （`√(a+bx+cx²)` 与 `√(b+2cx)` 配对——后者是前者的导数核，
   `∫q'·q^(k/2)dx` 族属单基幂法则，先在 P1 层识别 `q'` 关系）。
2. **椭圆路由层（W4b，依赖 `elliptic.rs` 广度）**：合并为四次被开方的
   `W(x)/√(Q(x))` 形后交 `elliptic::integrate_elliptic`（0.27.2 起 Legendre
   约化，`m=k²` 约定）。本层只做**合并 + 路由 + 诚实传递拒绝**，不自己实现
   一般四次根式约化。预估解锁取决于椭圆引擎对非 Legendre 四次的接受面，
   **不计入 W4a 的验收数**。
3. **其余拒绝**：Möbius t-形非有理、合并被开方次数 > 4、椭圆引擎拒绝——
   一律诚实回退（例 Q2 即为拒绝护栏例）。

**Euler 代换推广的关系**：`sqrt_quadratic` 的 Euler III（`t=√(c(x−r₁)/(x−r₂))`，
两有理根、数值证据门）与本节 Möbius 是**同一定理在不同基度数上的实例**：
MR-L 是「两个一次基」、Euler III 是「一个二次基的两根」。实现上共用同一个
`t²=u/v` 代换构造器（`x = (a−c t²)/(d t²−b)` 的有理反解 + `dx/dt`），
区别只在有理化后的单基/零基落点。不重复实现。

### 2.4 MR-C：线性×二次混合（13 例）

合并后被开方为**三次式**（`√((a+bx)·q)`）——同为椭圆（第三类形状），SymPy 对
代表例直接回退（§5 例 C1）。W4 范围：

- **做**：P2 共享因子可坍缩情形（00622 的 `(bx+cx²)^(5/2)` 含因子 `x`）；
  `x^(p/2)·(a+bx²)^(q/2)` 且 `p+q` 配对使 `x=t²` 后落单基的特例
  （00327：`(cx)^(3/2)·√(a+bx²)`，`x=t²` → `2c^(3/2)·t⁴·√(a+bt⁴)`——
  被开方四次，**仍椭圆**：诚实记录为路由层，不承诺初等）。
- **其余**：合并 → 三次/四次被开方 → `elliptic` 路由层（W4b）；拒绝即回退。

### 2.5 MR-G：`√u ± √v` 和（5 例）

**共轭有理化**（恒等式，无条件成立）：

```
R(x)/(√u+√v)^k  =  R(x)·(√u−√v)^k / (u−v)^k
```

仿射基下 `u−v` 是**常量或仿射**：常量化（00282/00349/00979/01143，`u−v` 为符号
常量）时分母彻底有理化，展开后剩余项只含 `√(u·v)` 单基积形 → §2.2 合并 →
`sqrt_quadratic`。分子和（00343：`(√(1−x)+√(1+x))² = 2+2√(1−x²)`）直接展开即
单基。**成立条件**：`u−v ≢ 0`；`u−v` 非常量时（一般情形）展开产生
`(u−v)^(−k)` 幂——**分母幂 ≤ 2 才接受**（预算纪律），否则拒绝。

### 2.6 MR-E/MR-F：分母 3/4 的分数幂混合（11 例）

**与 `binomial.rs` lcm 提升的关系**：`binomial` 的 `x=t^L` 只覆盖**单基**；
本节的推广是「**两基共用同一 lcm 提升**」的存在条件：

- **E1 坍缩为 Chebyshev 单基**：`x^m·(a+b·x^n)^(p/s)` 形的双基（`x` 与 `a+b·x^n`）
  先走 `binomial` 的 Chebyshev 三情形——它本来就是单判定定理（`s ≤ MAX_DENOM=6`
  已覆盖 3、4）。核验例：§5 例 E2，`(1+x²)^(1/3)/x^(11/3)` 的
  `(m+1)/n+p = −1 ∈ ℤ` 属情形 3，`t³=(1+x²)/x²` 有理化，t-形 `−3t³/2`。
  **W4 的工作只是保证多基检测不抢占这条已有路径**（归因桶按基个数分类，
  把 Chebyshev 可解形也划进了 multi-radical-base）。
- **E2 双仿射基的纯分母 3/4 情形**（01874：`(c+dx)^(1/3)/(a+bx)^(1/2)`；
  00248/00887/01650 等 1/4+1/2 混合）：`t^L = (a+bx)/(c+dx)`，`L = lcm(2,3)=6`
  或 `lcm(2,4)=4`——Möbius 反解后 `u = Δ/(d·t^L−b)` 使 `u^(1/2)=t^(L/2)·√…`
  **不完全**有理化（`L/2` 次幂乘 `t` 幂：`u^(1/2) = t^(L/2)/…` 要求 `L` 偶且
  商基同样以 `t` 幂表达——成立，因为 `v = Δ/(d t^L − b)·d⁻¹` 类反解把两基都写成
  同一 t^L 分式，`u^(p/2)·v^(q/3)` 化为 `t^(pL/2)` 次幂与 `t^L` 的有理式之积）。
  **接受条件**：两基仿射、所有指数分母整除 `L ≤ 4`（预算
  `MAX_MR_Q=4`——`L=6` 的 01874 超界，**列入 W4c 可选扩展，不进 W4a**）；
  t-形必须为有理式（结构检查）。
- **核验例**：§5 例 F1，`t⁴=(1+x)/(1−x)`，t-形 `4t⁴/(t⁴+1)` 有理，
  t-积分给出 `√2` 常量系数的 log/atan 族（正是 0.30.0 RT 代数根 + 证书根式层
  的既有能力面）。

### 2.7 MR-P：完全平方基（8 例）

`√((a+bx)²) = |a+bx|`——**不是** `a+bx`。0.27.3 的 `fold_linear_squares`
刻意不在非整数幂下折叠（`mod.rs` 既有测试 `linear_square_fold_keeps_radicands…`
钉死此语义）。本节采用 `halfpower.rs` 的**片层因子**先例：

```
((a+bx)²)^(k+1/2)  =  (a+bx)^(2k+1) · σ,   σ = (a+bx)·((a+bx)²)^(−1/2)
```

`σ` 在每个不含零点的区间上为 `±1` 常量，形式导数 `Dσ = 0`（微分域语义）；
证书侧 `σ` 即基 `(a+bx)²` 的根式生成元商——`certify.rs` 根式层以
`r²=(a+bx)²` 与 `r` 对 `(a+bx)` 的商关系判零（落在既有三角列机制内）。
处理后全式只剩其余基，降入相应子类。**数值符号证据**（同 `sqrt_quadratic`
S1 的 asin 门）：能对目标区间判定 `a+bx` 定号时可把 `σ` 直接折为 `±1`。
`a²−b²x⁴ = (a+bx²)(a−bx²)`（00545）按 P3 分解为两基后按 MR-Q 处理。

### 2.8 MR-I 嵌套根式（2 例）与 MR-R 倒数幂基（2 例）

- **MR-I**：最内层含 `√x` ⇒ `x = t²`（`dx = 2t dt`）把嵌套降一层；降层后若余
  单二次基（01039：`√(1−x−√x)` → `2t·√(1−t−t²)`，二次被开方）→ `sqrt_quadratic`；
  01588 需两次 `t²` 提升，余 `√(线性)` 单基 → `binomial`。去嵌套层数 ≤ 2
  （预算常量 `MAX_MR_NEST=2`），每层 t-形节点 ≤ `MAX_MR_SUBST_NODES`。
- **MR-R**：`u = 1/x` 把 `a+b/x` 基化为仿射基（`dx = −du/u²`），降入 MR-L
  （核验例 §5 R1：u-形 `−√(2u+1)/(u²(4u+3)^(3/2))`，再经 §2.2 Möbius，
  t-形 `t²(8t²−4)/(3t²−1)²` 有理）。

### 2.9 MR-J 与 MR-H：明确不做（理由）

- **MR-J**（2 例：`x^(5/2)(a+bx³)^(5/2)` 等）：合并被开方 `x·(a+bx³)` 为四次——
  椭圆；且 SymPy 对代表例只给超几何形（§5 例 C2 族）。归 W4b 椭圆路由评估，
  本波不做。
- **MR-H**（4 例：系数含 `√3` 常量或 `i`）：00732/00845/01893 是 **Const(k) 符号
  推理 + 常量根式**问题，与多基归约机械不同构（ALGEBRAIC_RT §7 已把符号常量塔
  判为 0.30.0 no-go）；01753 含 `i`，违反 `build.rs:124` 的实值 `I` 拒绝不变。
  全部诚实拒绝，另立项评估。

## 3. 接入点与输出形状

### 3.1 接入点

新模块 `ocas-calc/src/integral/multi_radical.rs`，入口
`integrate_multi_radical(ctx, expr, var) -> Option<Atom>`，挂入 `mod.rs` 链：

```
… sqrt_quadratic → binomial → 【multi_radical】 → exp_log → …
```

位置理由：(a) 单基引擎（`sqrt_quadratic`/`binomial`）保持对单基形状的**先 claim**
——多基归约只在 ≥2 基时触发，不抢既有答案形状（幂等不变式）；(b) 必须早于
`heuristic`（分部/Weierstrass 会在多基乘积上烧尽 `MAX_CHAIN_ENTRIES`）；
(c) 早于 `exp_log` 无副作用（形状不相交）。(d) MR-Q/MR-C 的椭圆路由层在模块
**内部**调用 `elliptic::integrate_elliptic`，不改变链上 `elliptic` 阶段位置。

**parts 纪律**（§1.3-7）：模块在 `chain::parts_active()` 作用域内**只**允许输出
「完整答案」或 `None`——其归约要么整体成功要么整体拒绝，不产生链内残项升级。

### 3.2 预算常量（新增，全部确定性）

| 常量 | 值 | 约束对象 |
|---|---|---|
| `MAX_MR_NODES` | 200 | 输入被积函数节点数 |
| `MAX_MR_BASES` | 4 | 不同根式基个数 |
| `MAX_MR_Q` | 4 | 指数分母上界（3/4 幂族；`L=lcm ≤ 4`） |
| `MAX_MR_SUBST_NODES` | 400 | 代换后 t-形节点数（对齐 `sqrt_quadratic` 的 `MAX_REENTRY_NODES`） |
| `MAX_MR_NEST` | 2 | 嵌套去根层数 |
| `MAX_MR_ROUNDS` | 3 | ≥3 基配对归约轮数（§2.2） |
| `MAX_MR_WORK` | 100 000 | 阶段总工作量（对齐 `MAX_SQRT_WORK` 的记账模型：每次全树扫描/代换按节点数记账） |

### 3.3 输出形状

- t-形回积分结果回代 `t = √(u/v)`（或 `t = (u/v)^(1/L)`、`x=t²`、`u=1/x`）后，
  答案含：`√(u/v)` 字面量、单基 `√(u·v)`、`log`/`atan`（带 `√Δ` 常量系数）、
  椭圆头 `EllipticF/E/Pi`（路由层）、片层因子 `σ`。
- 均不自匹配 `rational`/`risch`/`binomial`/`sqrt_quadratic` 入口模式
  （`√(u/v)` 商式与 `σ` 不被任何单基匹配器接受；`EllipticX` 头同理）。
- 实值：不引入 `I`（`build.rs:124` 不变式）；复值情形（被开方恒负等）拒绝。

## 4. 分支与片层语义（实值纪律，单独成节）

### 4.1 合并 `√u·√v = √(u·v)` 的成立条件与分支风险

复分析上 `√u·√v = ±√(u·v)`，符号依赖于分支。**接受规则**：

1. 仅当合并方向是**积 → 单根式**且合并后引擎能产出经证书认证的答案时执行；
2. 执行前要求**数值证据**：在积分变量的一个采样区间上 `u·v ≥ 0` 且
   `√u·√v` 与 `√(u·v)` 数值相等（主值）；证据不足 → 不合并，走 Möbius 或拒绝；
3. 商 `√u/√v = √(u/v)` **一律不合并**（商的分支 cut 更复杂），统一由
   `t = √(u/v)` 代换承载——代换本身即主值定义，分支语义由 §4.2 的片层因子承担。
4. 证书层**看不到**合并步骤（它认证的是最终 `D(F)−f≡0`，其中各根式以原始基
   出现）——合并只影响求解路径，不影响认证强度。这是「数值证据 + 符号证书」
   双门分工的又一实例（0.27.2 `kernel_subst` 确定性门先例）。

### 4.2 片层因子

`σ = (a+bx)·((a+bx)²)^(−1/2)` 与 halfpower 的
`cos(u/2)·(1−sin²(u/2))^(−1/2)` 同一机制：形式导数为零（逐区间常量），
使答案在每个连通区间上是真反导数。文档化规则：

- 每个 `σ` 的发射必须伴随注释级记录（目标区间、定号依据）；
- 有数值符号证据时折为 `±1`；否则保留 `σ` 节点（用户可见、可数值求值）；
- `σ` 参与证书：根式层关系 `r² = (a+bx)²` + 商关系，三角列判零（既有机制）。

### 4.3 Möbius 代换的定义域

`t = √(u/v)` 要求 `u/v ≥ 0` 的区间；代换答案在 `u/v > 0` 的每个区间成立，
端点处由连续性延拓。`u/v < 0` 的区间（虚 `t`）**不做**——实值输出纪律
（§3.3）。SymPy 对同例给出含 `acosh`/`asin` 的分段答案（§5 L1）印证两侧分支
各自成立；oCAS 只发实分支。

## 8. 风险与实测陷阱预判

1. **分支错案是第一风险**。`√u·√v=√(uv)` 在 `u,v<0` 区间差一个符号；
   0.27.1 已有 `rational_square_root` 把和式误判为平方的错案先例
   （BENCHMARK_RESULTS 0.27.2 节）。对策：§4.1 数值证据门 + 证书双门，
   并在 `integral_certify.rs` 增错案护栏（清单 9）。
2. **t-形回积分的链预算**。Möbius t-形是 `deg ≤ 6` 的有理式，但其 RT 路径
   （0.30.0 代数根）有 `MAX_RT_DEGREE=8` 等预算；t-形回积分经 `integrate_raw`
   会消耗 `MAX_CHAIN_ENTRIES`——参照 `sqrt_quadratic` 的 `MAX_SQRT_WORK`
   记账模型把代换扫描计入 `MAX_MR_WORK`，防止「扫描免费、回积分爆炸」。
3. **parts 作用域回归**（`rubi-01646` 教训）：多基归约若在 parts 内层把残项
   升级为含 `log/atan` 的完整答案，分部续算会烧尽链预算。清单 8 的断言 +
   §3.1-(d) 纪律即为此设。
4. **`normalize` 不合并 `sqrt` 头与 `Pow` 分数幂**（halfpower 模块文档 60–67 行
   记录的既有事实）：基收集必须同时识别 `sqrt(S)` 与 `S^(p/2)` 两种写法并归一到
   同一基——P1 直接复用 `certify.rs` 根式层的 `(base, q)` 分组思路
   （`rewrite_radicals`/`radical_group`，certify.rs:379-451），避免第三份
   基收集实现漂移。
5. **符号系数的 Möbius 反解**：`a·d−b·c ≢ 0` 的判定在符号系数下是表达式
   判零——用 `collect_terms` 折叠后判零，判不了即拒绝（诚实）。题库 27 例
   MR-L 全部带符号系数，此判定是解锁前提，**实测时首先验证**。
6. **椭圆路由层的解锁数不可提前承诺**：`elliptic.rs` 对非 Legendre 四次的
   接受面决定 MR-Q/MR-C 第 2 层的实际收益；规格验收只把坍缩层（§2.3-1）
   计入 W4a 目标，路由层单列度量。
7. **`x·x` 型线性匹配潜伏错案**（ALGEBRAIC_RT 偏差记录第 3 条）提醒：基解析
   的 `linear_form` 复用必须经过 0.30.0 已修复版本；多基收集器对重复变量因子
   同样要返回 `None` 而不是误判为仿射。
